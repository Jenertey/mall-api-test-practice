# Mall 接口自动化测试练习：测试计划

## 目标

验证 Mall 后台核心接口在正常、异常和权限场景下的行为，并检查商品与订单数据在数据库中的一致性。

## 范围

- 管理员登录与鉴权
- 商品列表、详情、创建和删除
- 订单列表与详情
- 商品和 SKU 库存数据
- 响应字段、分页字段和业务码

## 不在范围

- Mall 前端视觉回归
- 支付渠道真实扣款
- 生产环境数据写入
- Mall 源码本身的单元测试

## 环境

- 后台 API：`MALLTEST_ADMIN_URL`
- 数据库：`MALLTEST_DB_*`，可选
- 测试数据：由 `ProductFactory` 生成，SKU 使用唯一编号
- 写操作：只在一次性环境中启用

## 进入条件

- 后台健康检查通过
- 管理员账号可登录
- 测试环境允许清理测试商品

## 退出条件

- 只读接口用例全部通过
- 失败的接口有请求、响应和复现步骤
- 写操作完成后测试商品已删除
- 数据库检查没有负库存或孤儿 SKU

## 风险

- Mall 的分页字段和业务码可能在版本升级后变化
- 写操作接口依赖分类、品牌等基础数据
- 库存表结构可能随版本调整，数据库用例应可单独跳过
- 离线契约测试只验证样本结构，不能替代对真实服务的联调
